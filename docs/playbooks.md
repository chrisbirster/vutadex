# Playbooks

The internal hierarchy is:

```text
Playbook -> Formation -> Personnel -> Play -> Assignment
```

Offensive assignments include route, block, handoff, motion, read and option. Defensive assignments include man, zone, rush, spy, contain and run fit.

Play definitions use normalized field coordinates so the same route can be rendered at any viewport size. The first core library intentionally remains small enough to balance and test.

External sites such as Madden School are research references only. VutaDex should implement standard football concepts in original data and presentation rather than copy proprietary diagrams, descriptions or curated databases.
