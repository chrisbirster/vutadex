# M1 — Deck Management

Implemented commands:

- `node index.ts deck create "Spanish" --description "Vocabulary"`
- `node index.ts deck list`
- `node index.ts deck show 1`
- `node index.ts deck rename 1 "Spanish basics"`
- `node index.ts deck describe 1 "Everyday words"`
- `node index.ts deck describe 1 --clear`
- `node index.ts deck delete 1` (interactive confirmation)
- `node index.ts deck delete 1 --yes` (explicit noninteractive confirmation bypass)

IDs are positive integers. Names are case-insensitively unique (enforced by service validation), trimmed, 1–120 characters, and reject control characters; descriptions have a 2,000-character maximum. Deleting a deck cascades to its cards. CI tests run on Ubuntu, macOS and Windows.

Note: The current uniqueness rule is enforced in application logic, not by a SQLite unique index; concurrent writers must be addressed if the app adds concurrency later.

## Milestone release branch policy

When promoting `dev` to `main`, use a GitHub merge commit (not squash) to preserve shared ancestry. This avoids artificial conflicts at the next milestone. Feature PRs targeting `dev` may continue to use squash merges.
