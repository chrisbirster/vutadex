# M3 — FSRS-7 scheduling

The scheduler is a dependency-free pure TypeScript implementation of FSRS-7. It has **34 pinned default weights**, a slow and fast memory trace, and a two-component forgetting curve with numerical interval inversion. The implementation is based on open-spaced-repetition/fsrs-rs commit `0a5737406a0c5c7a5259b144738cbe4a0b649d76`. Numerical golden vectors come from kutyel/haskell-fsrs commit `c26a0ac65b69bbb771603aa9ff720cd6fb780af5` (MIT).

Commands:

```sh
node index.ts due
node index.ts due 1
node index.ts card review 1 good
node index.ts card schedule 1
node index.ts card history 1
node index.ts card undo 1
```

Ratings: Again=1, Hard=2, Good=3, Easy=4. Every rating immediately updates a card's due date and memory state, with default target retention 0.9. All review timestamps and due dates are UTC ISO-8601. Intervals are continuous (minimum 1 second, maximum 100 years); first reviews ignore elapsed time. New cards without a schedule count as due.

Database migration `user_version=2` is transactional and preserves M1/M2 decks and cards. `review_events` appends review and undo events; `card_schedules` stores the current snapshot. Undo restores the pre-review snapshot and appends a reversal event rather than deleting previous events. Deleting a card/deck still cascades and removes the corresponding local history.

**Constraints:** No personalized parameter optimization; custom parameters are not exposed. Future algorithm revisions must migrate schedules explicitly (their version is stored). Interactive study sessions, queues and limits are M4.
