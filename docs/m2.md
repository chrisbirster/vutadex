# M2 — Card management

All commands are local and persist to SQLite.

```sh
node index.ts deck create Spanish
node index.ts card add 1 --front "hola" --back "hello"
node index.ts card add 1 --front "Line one\nLine two" --back "Answer"
node index.ts card list 1
node index.ts card search 1 hello
node index.ts card list 1 --search hola
node index.ts card show 1
node index.ts card edit 1 --back "Hello!"
node index.ts card delete 1
node index.ts card delete 1 --yes
```

An interactive `card add <deck-id>` prompts for front and back if a terminal is attached. In interactive prompts, type `\\n` for a line break. On the command line, use shell-supported literal newlines (for example, ANSI-C quoting on bash/zsh).

Card IDs and deck IDs must be positive safe integers. Front/back are trimmed and restricted to 1–10,000 characters with no NUL. Search is case-insensitive within a deck. Deletes require confirmation, or the explicit `--yes` option for scripts. Review scheduling is reserved for M3.
