# Roadmap

| Milestone | Outcome |
|---|---|
| M0 | Production-shaped Go/Solid foundation |
| M1 | PostgreSQL + passwordless SES accounts |
| M2 | Persistent football-universe model |
| M3 | Deterministic server football engine |
| M4 | Formation/personnel/playbook system |
| M5 | Animated X/O field and semantic replay |
| M6 | Human-vs-CPU Coach Mode |
| M7 | Live human-vs-human Coach Mode |
| M8 | GM/franchise systems |
| M9 | Seasons, records and the Dex |
| M10 | Direct QB/RB/MLB Player Mode |
| M11 | Real-football live/replay adapters |
| M12 | Public-beta hardening and operations |

## Release gates

The first meaningful playable release is M6: a complete coach-controlled game against CPU. Multiplayer arrives at M7. GM depth should not delay proving that calling plays on the X/O field is fun.

The repository bootstraps interfaces and data models for later milestones early, but a milestone is only complete when its acceptance criteria in `milestones/m0-m12.md` are met and tested.
