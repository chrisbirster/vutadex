- [x] Go 1.26 `net/http`, graceful shutdown and structured logging.
- [x] Vite -> `internal/web/dist` -> `go:embed` single-binary flow.
- [x] Solid 2 next, Solid Router, StyleX, TypeScript.
- [x] SPA deep-link fallback and immutable hashed-asset caching.
- [x] Host split for `vutadex.com` and `game.vutadex.com`.
- [x] Docker, Fly, CI, Atlas and branching docs.
- [ ] Generate and commit `pnpm-lock.yaml`/`go.sum` from the first dependency install.
