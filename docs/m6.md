# M6.1 — Progress statistics and scheduled due-date forecast

Run `node index.ts stats`, `node index.ts stats <deck-id>`, or `node index.ts stats [deck-id] --days N` (1–90, default 7) from source. The installed CLI command is `vdex stats`.

The read-only summary reports **active** cards (manual plus non-retired generated cards), new vs reviewed, cards scheduled due now, cards overdue before today, completed sessions, and non-undone rating events in the trailing seven 24-hour periods. Deck-specific completed-session counts include deck-scoped sessions; global sessions only appear in global totals.

The forecast bins the **current saved** FSRS due dates by UTC calendar day starting today. Overdue cards from prior UTC days are listed separately, and new cards have no schedule and are excluded from the daily projection. Today’s bucket includes every scheduled card dated today, including earlier times today. This is **not** a prediction of future reviews, retraining, daily study workload, or the effect of studying.

Results depend on the current clock and the user's database. No network access, schema migration, updates, or scheduler changes are needed. Tests use fixed UTC clocks for midnight boundaries, undo semantics and retired note exclusion. Later M6 work will add portability and backup/restore independently.
